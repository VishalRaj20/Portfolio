## 🎯 Features

- ⚡ **Hero Section** with animated gradients, name reveal, and smooth intro.
- 🛠️ **Skills Showcase** with icons and categorized strengths.
- 💼 **Project Portfolio** with real data, tech stack tags, and external links.
- 📄 **Resume Viewer** – Opens your resume in a new browser tab.
- 📬 **Contact Form** integrated with [EmailJS](https://www.emailjs.com/) + toast notifications + spinner.
- 📱 **Responsive Design** – Fully optimized for all screen sizes.

## 🚀 Getting Started

Clone and run locally:

```bash
git clone https://github.com/VishalRaj20/portfolio.git

cd portfolio

npm install

npm run dev
```
